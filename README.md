# Boleta Justa · Web

Versión pública de [Boleta Justa](https://github.com/MaxxyGuti3rr3z/boleta-justa):
auditoría de boletas de EJESA (Jujuy) que corre **100% en el navegador**.

- El PDF se lee con pdf.js en tu dispositivo: **no se sube, no se guarda, no se comparte**.
- Compara los cargos con los cuadros oficiales del Boletín Oficial de Jujuy.
- Explicación en lenguaje llano, con glosario.
- Historial local: guardá análisis en este navegador, exportalos a JSON o importalos en otro dispositivo.

Código fuente y tests: https://github.com/MaxxyGuti3rr3z/boleta-justa

Orientación vecinal, no dictamen legal. Si algo no coincide, pedí el desglose a EJESA.
